# Data Model — 031 Composição por grafos de nós e contratos de shader estruturados

## Contrato de shader (C2, `scene/shaders`)

| Entidade                        | Dados                                                                                                                                                                                                                                                                                                                                                                               | Regras                                                                                                                                                       |
| ------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `WgslResource` (novo)           | `name` (identificador WGSL), `binding` (`storage` + acesso, `uniform`, `texture` {dimensão, amostra, multiamostrada, profundidade}, `storage-texture` {formato, acesso}, `sampler`, `sampler-comparison`), `type` (`StructSchema` [+ `array`] ou tipo WGSL), `frequency` (`frame`/`stage`/`batch`/`draw`), `provider` (`{pool}`, `{consumer}`, `{texture}`, `{scene}`, `'private'`) | É um `WgslModule` sem fonte de função; incluído por `requires`; dois recursos com o mesmo nome no mesmo shader → `symbol-conflict`, salvo o mesmo objeto     |
| `WgslModule` (alterado)         | + `resources` (derivado dos `requires` que são recursos), + `instanced` (símbolos renomeados por instância)                                                                                                                                                                                                                                                                         | Fonte com `@group`/`@binding` → `manual-binding` na criação; referência a variável global fora do fecho de dependências → `unresolved-reference` na montagem |
| `ComposedShader` (alterado)     | + `bindings`: `{ resource, group, binding, visibility }[]` e `groups` por frequência                                                                                                                                                                                                                                                                                                | Grupo = posto da frequência entre as presentes; ligação = ordem do nome; determinístico; conferido contra os limites do dispositivo (`limit-exceeded`)       |
| `SharedConstant` (novo)         | `name`, `value`, `type`                                                                                                                                                                                                                                                                                                                                                             | Gera o valor TS e um módulo WGSL `const`; cada constante definida uma vez no motor                                                                           |
| `PipelineDescriptor` (alterado) | − `consumes`; + `family` (família de desenho); + `constants` (`override`)                                                                                                                                                                                                                                                                                                           | O consumo é o conjunto de recursos alcançados pelos pontos de entrada                                                                                        |
| `PreparedPipeline` (alterado)   | + `groupsOf(frequency) → { index, spec, dynamic }[]`                                                                                                                                                                                                                                                                                                                                | Estágios não usam índices literais                                                                                                                           |
| `ScenePoint` (generalizado)     | ponto WGSL + contribuintes `{ module, order, resources }` declarados por Resources (`getSceneContributions()`)                                                                                                                                                                                                                                                                      | Contribuintes compostos em ordem; sem contribuinte → pronto; composição falha → pronto + `extensionRejected`                                                 |

## Pontos de cena novos (C3)

- `light_visibility(p, n, light) -> f32` — produto ordenado; contribuintes: sombra (`ShadowMap` que projeta), água
  (`WaterSurface`, cáusticas). Pronto: `1.0`.
- `scene_light(p) -> SceneLight { direction, color, slot }` — luz que chega; pronto: direção padrão
  (`DEFAULT_LIGHT_DIRECTION`), sem slot.

## Grafo (C2, `scene/graph`)

| Entidade                         | Dados                                                                                                                                                                                                                           | Regras / estados                                                                                                                                                                                      |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `NodeDefinition` (novo)          | `name` (único no registro), `level` (`point`/`set`), `inputs`/`outputs` (porta → tipo), `params` (nome → `FieldType`, padrão), `code` (módulo WGSL) ou, em `set`, `kernels` + `sets` (schema, capacidade, contagem), `contexts` | Imutável; validado na criação (assinatura casa com as portas; símbolos; montagem em cada contexto)                                                                                                    |
| `NodeRegistry` (novo)            | nome → definição                                                                                                                                                                                                                | Bibliotecas da C3 registram; usado por `fromJSON`                                                                                                                                                     |
| `NodeGraph` (novo, Resource)     | `nodes` (id → definição + valores), `links` (de, porta → para, porta), `outputs`, `target` (`WgslPoint` para grafos de ponto; fase para grafos de conjunto)                                                                     | Identidade = hash da forma; parâmetros no registro tipado gerado (`<alias>_<hash>`, pool por forma); valor novo → `poolWritten`, sem recompilar; topologia nova → revisão +1 → recompila em transição |
| `Subgraph` (novo)                | `NodeGraph` + parâmetros expostos                                                                                                                                                                                               | Usado como nó; código emitido uma vez por shader                                                                                                                                                      |
| `CompiledPointGraph`             | módulo WGSL que implementa o ponto alvo, struct de parâmetros, carregador                                                                                                                                                       | Memorizado por forma; cada nó num `let`                                                                                                                                                               |
| `GraphFlow` (novo, Flow)         | slots (entradas, saídas, registro do grafo), kernels por nó, ordem topológica                                                                                                                                                   | Estados `stale` → (`frameRecorded`) → `clean`; `stale` em `poolWritten` do registro, `resourceReady`/`poolWritten` de entradas, ou nós de tempo                                                       |
| `SetCount` (novo, schema)        | `count: u32`, `dispatch: vec3u` (+pad), `draw` (5 × u32)                                                                                                                                                                        | Escrito só pela GPU (`CountToArgs`); descritor `indirect` do grafo                                                                                                                                    |
| `GraphGeometry` (novo, Geometry) | vértices `array<MeshVertex>`, índices, `indirect`, `wireEdges` — todos `upload: 'never'`                                                                                                                                        | Possuída (`owns`) pelo `GraphFlow`; desenhada pelo caminho da `ParametricSurface`                                                                                                                     |
| `MeshVertex` (novo, schema)      | `px, py, pz, nx, ny, nz, u, v: f32`                                                                                                                                                                                             | 32 B, mesmo layout do buffer de vértices                                                                                                                                                              |

## Registros tipados (substituem `extensionRecordSchema`)

- Função de ponto da 009: `StructSchema` gerado dos `params` (nome → tipo), `<alias>_<hash>`, campos com o tipo
  declarado + `revision`; pool `<ponto>:<hash>`.
- `FieldBuiltinRecord`: campos dos campos prontos (`a`, `b`, `s`, `kind`) com códigos de `SharedConstant`.
- `CameraFnEntry { camera, world, record }`, `TransformFnPair { transform, record }`.

## Validação

- Portas: tipos iguais ou conversão declarada pelo tipo da porta (escalar → vetor por repetição); demais → erro.
- Ciclos: caminho completo, inclusive através de sub-grafos.
- Contexto: nós só de `fragment` (derivadas de tela) usados em outro contexto → erro nomeando o nó.
- Não finitos: um único módulo `finite` aplicado na saída do grafo e na saída das funções da 009.
- Limites: ligações por grupo, storage e uniform por estágio, conferidos na montagem.
