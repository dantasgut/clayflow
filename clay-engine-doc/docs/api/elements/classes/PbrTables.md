# Class: PbrTables

Defined in: [src/elements/material/pbr/PbrTables.ts:18](https://github.com/dantasgut/clayflow/blob/9be3ad597671ac7e8dc53b879ebefd3eb752cbd6/src/elements/material/pbr/PbrTables.ts#L18)

Tabelas pré-integradas do sombreamento físico (Camada 3, spec 011): a DFG `rgba16float` 32×32 — por (n·v, rugosidade),
o especular de F0 = 1 separado em E = F0·A + B e o albedo do sheen — que compensa o múltiplo espalhamento e fecha a
energia entre as camadas. Gerada na GPU uma vez pelo `PbrTablesFlow` (sem arquivo binário) e lida pelo avaliador do
fechamento (`pbr_dfg`, `pbr_sampler`). Uma por cena, inserida pelos estágios padrão.

Troca o dado e os descritores em pool de uma vez — o Resource cujo layout depende do próprio dado (ex.: o registro
tipado de uma função de ponto quando a forma dos parâmetros muda; spec 031, R8). `getDescriptors()` já devolve os
novos; `previous` são os de antes. Fora da cena, só troca o dado; na cena, a C2 libera os slots nos pools antigos,
ocupa os dos novos com `next` e recompõe a entidade (`entitiesRecomposed`: registros e conjuntos dos estágios).
